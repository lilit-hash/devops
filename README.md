## Сети в Linux - 
Развертывание полноценной корпоративной сети из 5 виртуальных машин:

3 рабочих станции (ws11, ws21, ws22)

2 роутера (r1, r2) с IP-переадресацией

Настройка маршрутизации между разными подсетями (10.10.0.0/18, 10.100.0.0/16, 10.20.0.0/26)

Продвинутый firewall и NAT — Реальная защита сети:

Настройка iptables с разными стратегиями (запрет→разрешение vs разрешение→запрет)

Реализация SNAT (маскирование локальных IP для выхода в интернет)

Настройка DNAT с пробросом портов (внешний 8080 → внутренний 80)

Блокировка/разрешение ICMP, SSH, HTTP трафика

DHCP-сервер с резервацией — Профессиональная настройка:

Динамическая раздача IP-адресов в разных подсетях

Жесткая привязка IP к MAC-адресам (для серверов)

Автоматическая конфигурация шлюзов и DNS

SSH-туннелирование — Создание безопасных каналов:

Local TCP forwarding для доступа к защищенным сервисам

Remote TCP forwarding для организации обратного доступа

Обход фаерволов через зашифрованные туннели

Диагностика и мониторинг — Профессиональные инструменты:

Анализ трафика в реальном времени через tcpdump

Трассировка маршрутов с помощью traceroute

Проверка доступности через nmap (даже при заблокированном ping)

Измерение скорости канала с помощью iperf3
